# AEShapeToSVG

After EffectsのシェイプレイヤーをSVGファイルに書き出す、Windows用のツールです。
Illustratorと連携すると、SVGとAIファイルを同時に書き出せます。

## 目的

After Effectsで作成したシェイプを、他のアプリでも使えるベクターデータとして取り出します。
選択したシェイプレイヤーのContentsを、カレント時間の静止画として保存します。
書き出し対象は、選択したシェイプレイヤー1枚です。

SVGのキャンバスはコンポジションと同じサイズです。レイヤーのアンカーポイントと位置を反映します。
元のAEプロジェクトやレイヤーは変更しません。

### 対応するシェイプ

- 四角・角丸四角・楕円・多角形・スター・パス。
- 塗り・線・破線。
- パスの結合・オフセット・リピーター・トリミング・角を丸くする。
- グループ内のトランスフォーム。

グラデーションは単色に置き換えます。**グラデーションの塗りは赤、線は青**になります。
非表示のContentsと、未対応のContentsオブジェクトは書き出し対象から除外します。

レイヤーの回転・スケール、親レイヤーの変換、マスク、エフェクト、3D投影は反映しません。
多角形・スターの小数の頂点数など、一部の設定は変換できません。
PDF出力は未対応です。

## インストール方法

### 必要な環境

- Windows版After Effects。
- Windows PowerShell（SVG変換アプリの起動に使用）。
- Windows版Illustrator（AIファイルも書き出す場合）。

### ダウンロードと配置

1. [Releases](https://github.com/bryful/AEShapeToSVG/releases)から、配布用アーカイブをダウンロードして展開します。
2. 以下のファイルを、書き込み可能な任意のフォルダーへ配置します。アーカイブ内の階層を保ってください。

```text
export-shapes.jsx
export-shapes.exe
(export-shapes)/
    export-core.js
    export-runner.js
    export-settings.js
    export-illustrator.js
```

**`export-shapes.exe`は`export-shapes.jsx`と同じ場所に置いてください。**
`(export-shapes)`フォルダーも必要です。更新するときは、スクリプトと補助ファイルをまとめて置き換えてください。

ソースコードから用意する場合は、Visual Studio 2026で`AEShapeToSVG.slnx`を開き、
Release／x64でビルドします。exeは`script`フォルダーへ自動配置されます。
詳細は[開発・ビルド手順](asts/README.md)を参照してください。

### After Effectsの設定

AEの環境設定にある「スクリプトとエクスプレッション」で、
**「スクリプトによるファイルへの書き込みとネットワークへのアクセスを許可」**を有効にします。
項目の表記はAEのバージョンによって異なる場合があります。

## 実行方法

1. AEでコンポジションを開き、書き出したいシェイプレイヤーを1枚だけ選択します。
2. タイムインジケーターを、書き出したい時間へ移動します。
3. 「ファイル → スクリプト → スクリプトファイルを実行」から`export-shapes.jsx`を選びます。
4. 表示されたダイアログでオプションを設定し、「SVGを書き出す」を押します。
5. 「名前を付けて保存」ダイアログで、保存場所とファイル名を指定します。

初期ファイル名は`コンポジション名_レイヤー名.svg`です。別名で保存できます。
初期ファイル名の禁止文字は置換します。
既存の出力ファイルを上書きする場合は確認が表示されます。

最後に指定した保存先フォルダーは記憶され、次回以降の初期フォルダーになります。
まだ指定していない場合はaepのあるフォルダー、プロジェクトが未保存の場合はドキュメントを使用します。
「保存先の記憶を解除」で、aepのあるフォルダーへ戻せます。

### オプション

| 項目 | 動作 |
| --- | --- |
| 中間JSONをSVGと一緒に残す | ONにすると、SVGと同じ名前・同じ場所にJSONも保存します。標準ではSVGのみを残します。 |
| AIも書き出す | ONにすると、SVGと同じ名前・同じ場所にAIも保存します。Illustratorが必要です。 |
| Illustratorを選択／バージョン変更 | 使用する`Illustrator.exe`を選び直します。選択した場所は記憶されます。 |
| アニメーションがある場合はエラーにする | Contents・アンカーポイント・位置にキーフレームや有効なエクスプレッションがある場合、書き出しを中止します。 |

アニメーション禁止をOFFにした場合は、カレント時間でエクスプレッションを適用した値を書き出します。

### AIファイルも書き出す場合

「AIも書き出す」をONにしてください。Illustratorを自動検出し、見つからない場合は
ファイル選択ダイアログで`Illustrator.exe`を指定します。
複数のバージョンがある場合は、初回の自動検出では最も新しいものを使用します。
別のバージョンを使いたい場合は「Illustratorを選択／バージョン変更」で指定してください。

AI出力のON／OFFとIllustratorの選択は、次回以降も引き継がれます。
変換後、Illustratorは起動したままになり、変換用に開いたドキュメントだけを閉じます。
処理中はIllustratorの起動や応答を待つため、完了までお待ちください。

### エラーが出た場合

エラーダイアログに表示される作業フォルダーを確認してください。
変換失敗時は、調査用の中間JSONやログを残します。
AI変換だけが失敗した場合、先に保存されたSVGは残ります。

Illustratorが見つからない場合は実行ファイルを選び直してください。
初回起動時の確認画面などが表示されている場合は、それを完了してから再実行してください。

詳細な対応範囲や制限は[スクリプトの説明](script/README.md)を参照してください。
