# Shape Contents JSON exporter

AEの「ファイル → スクリプト → スクリプトファイルを実行」で `export-shapes.jsx` を実行します。
`(export-shapes)/export-core.js` も相対位置を維持して配置してください。Shapeレイヤーを選択し、保存先を指定します。
AEの環境設定でスクリプトによるファイル書き込みを許可してください。

標準はカレント時間の静止画です。Expression適用後の値を取得します。
「Reject animation」を有効にするとContents内のキーフレーム・有効なExpressionをエラーにします。
レイヤーTransform、親、マスク、エフェクトは出力しません。

対応Contents: 四角、楕円、多角形/スター、パス、オフセット、リピーター、塗り、線、
グラデーション塗り、グラデーション線、パスの結合、パスのトリミング、入れ子グループとそのTransform。
オフセット、リピーター、パスの結合は演算子とパラメーターを保存し、形状への展開は行いません。
パスの結合は `kind: "mergePaths"` とし、結合モード（`ADBE Vector Merge Type`）の評価値とContents内の順序を保存します。
パスのトリミングは `kind: "trimPaths"` とし、開始・終了（%）、オフセット（度）、
複数シェイプの処理モードを評価して保存します。トリミング後のパス生成は変換アプリ側で実装します。
線のダッシュ等の子プロパティも保存します。未対応のContents演算子は保存前にエラーにします。

グラデーション塗りは赤（RGBA `[1,0,0,1]`）の通常塗り、グラデーション線は
青（RGBA `[0,0,1,1]`）の通常線に置き換えてJSONに保存します。
塗り・線全体の不透明度、線幅、線端、結合、ダッシュ、合成設定などは引き継ぎます。
グラデーション固有の設定と色・不透明度ストップは保存しません。
置換だけを理由に `complete: false` にしたり、継続確認を表示したりしません。
AEの元レイヤーは変更しません。アニメーション禁止モードでは省略する設定も検査します。

ファイル名の禁止文字を置換し、同名選択レイヤーは連番を付けます。
全レイヤーの取得・JSON化後に保存し、既存ファイルの上書きは確認します。
I/Oエラーで途中停止した場合、既に保存されたファイルは残ります。

AE未インストール環境での確認:

```powershell
node script/tests/export-core.test.cjs
```

モックによる取得・シリアライズ確認です。ScriptUI、File、AE固有のプロパティ構造、
実際のExpression評価はAE環境で検証してください。
